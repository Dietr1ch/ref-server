#+title: Demo webserver
#+subtitle: axum + diesel + PostgreSQL demo
#+author: Dietr1ch

A minimal but complete Rust web server built with [[https://axum.rs][axum]] and
[[https://diesel.rs][Diesel]], backed by PostgreSQL.  Intended as a reference
for project scaffolding: Nix dev shell, database migrations, structured logging,
and a clean REST API.

* Prerequisites

- [[https://nixos.org/download][Nix]] with flakes enabled
- A running PostgreSQL instance (version 14+)

* Quick start

** 1. Enter the dev shell

#+begin_src fish
  nix develop
#+end_src

This sets ~DATABASE_URL~ and ~LISTEN_SOCKET~ automatically and makes ~diesel~,
~cargo~, and ~psql~ available.

** 2. Create the database

#+begin_src fish
  just setup
#+end_src

This runs ~diesel setup~ (creates the database if missing) then applies all
pending migrations.

** 3. Start the server

#+begin_src fish
  just run
#+end_src

The server listens on ~$LISTEN_SOCKET:="0.0.0.0:3000"~.

** 4. Try it out

Open this file in Emacs with ~verb-mode~ enabled, then place point on any
heading under the [[*API reference][API reference]] section below and press ~C-c C-r C-r~
to send the request.

* API reference

All endpoints return JSON.  Errors follow the shape ~{"error": "message"}~.

The headings below are live requests — open this file in Emacs with ~verb-mode~
and press ~, r r~ (~C-c C-r C-r~) while on any of them to send the request.

** demo-server                                                        :verb:
template http://localhost:3000

*** Health check
get /health

*** List users
get /users

*** Get user
get /users/<uuid>

*** Create user
post /users
Content-Type: application/json

{"name": "Alice", "email": "alice@example.com"}

* Configuration

The application reads these environment variables:

| Variable        | Default                                    | Description                  |
|-----------------+--------------------------------------------+------------------------------|
| ~DATABASE_URL~  | ~postgres://demo:demo@localhost:5432/demo~ | PostgreSQL connection string |
| ~LISTEN_SOCKET~ | ~0.0.0.0:3000~                             | Socket address to listen on  |
| ~RUST_LOG~      | ~demo_server=info,tower_http=info~         | Tracing/logging filter       |

Variables can be set in a ~.env~ file (loaded automatically on startup).

* Development

** Project layout

- ~src/routes/mod.rs~ — axum router and all handlers
- ~src/models.rs~ — Diesel model structs
- ~src/bin/server.rs~ — entry point, logging, connection pool, auto-migrations
- ~src/schema.rs~ — Diesel table! macro (auto-generated by ~diesel print-schema~)
- ~migrations/~ — SQL migration files
- ~flake.nix~ — Nix dev environment
- ~Justfile~ — common task runner commands

** Common commands

| Command                 | Description                           |
|-------------------------+---------------------------------------|
| ~just run~              | Start the development server          |
| ~just check~            | Run ~cargo check~                     |
| ~just test~             | Run ~cargo test~                      |
| ~just lint~             | Run ~cargo clippy -- -D warnings~     |
| ~just fmt~              | Format code with ~rustfmt~            |
| ~just migrate~          | Run pending Diesel migrations         |
| ~just migration <name>~ | Create a new migration scaffold       |
| ~just db-reset~         | Drop and recreate the database        |
| ~just ci~               | Full CI pipeline: check + test + lint |

Run ~just~ (no arguments) to see the full list.
