#+title: ref-server
#+subtitle: axum + diesel + PostgreSQL reference implementation
#+author: Dietrich Daroch

A minimal but complete Rust web server built with [[https://axum.rs][axum]] and
[[https://diesel.rs][Diesel]] (via [[https://docs.rs/diesel-async][diesel-async]]),
backed by PostgreSQL.  Intended as a reference for project scaffolding:
Nix dev shell, async database migrations, structured logging, and a clean REST API.


* Prerequisites

- [[https://nixos.org/download][Nix]] with flakes enabled
- [[https://devenv.sh/getting-started/][~devenv~]] to setup the environment
- Documentation and Environment rely on ~org-mode~ with,
  - ~babel~ to render and run code blocks
  - ~verb-mode~ to run HTTP requests


* Quick start

** 1. Start background services

#+begin_src fish
  devenv processes up
#+end_src

This starts,
- PostgreSQL listening on a Unix socket (~$DATABASE_URL~)
- static-web-server listening on ~$WEB_LISTEN_SOCKET:=localhost:3000~

Press ~Ctrl+C~ to stop.

** 2. Create the database

#+begin_src fish
  just db-setup
#+end_src

This runs ~diesel setup~ (creates the database if missing) then applies all
pending migrations.

** 3. Start the server

#+begin_src fish
  just run
#+end_src

The API server listens on ~$API_LISTEN_SOCKET:="0.0.0.0:3001"~.

** 4. Try it out
Open this file in Emacs with ~verb-mode~ enabled, then place point on any
heading under the [[*API reference][API reference]] section below and press ~C-c C-r C-r~
to send the request.


* API reference
All endpoints return JSON.  Errors follow the shape ~{"error": "message"}~.

The headings in the API docs can be queried using ~verb-mode~. Use ~, r r~ (~C-c
C-r C-r~) while on any of them to send the request.

- [[./docs/api/health.org][/health]]
- [[./docs/api/users.org][/users]]



* Configuration

The application reads these environment variables:

| Variable            | Description                                |
|---------------------+--------------------------------------------|
| ~DATABASE_URL~      | PostgreSQL connection string               |
| ~WEB_LISTEN_SOCKET~ | Socket address to listen on for static Web |
| ~API_LISTEN_SOCKET~ | Socket address to listen on the API server |
| ~SERVER_LOG~        | Tracing/logging filter                     |

Variables can be set in a ~.env~ file (loaded automatically on startup).
A ~.env.example~ file is provided as a starting point.

** API server
*** CLI flags
Command line arguments override environment variables

~--database-run-migrations~ :: Run pending migrations at startup
~--database-connect-timeout <s>~ :: Connection timeout (default ~5s~)
~--database-pool-size <n>~ :: Maximum pool connections (default ~8~)


* Development

** Project layout

- ~docs/~ :: Documentation using source blocks and ~verb-mode~
  - ~api/~
  - ~db/~
  - ~web/~
- ~migrations/~ :: SQL migration files
- ~src/~
  - ~bin/~
    - ~server.rs~ :: entry point, logging, connection pool, auto-migrations
  - ~routes/~ :: axum router; delegates to per-resource handler modules
    - ~health.rs~ :: ~/health~: health-check endpoint
    - ~users.rs~ :: ~/users~: user CRUD handlers
  - ~models/~
    - ~user.rs~ :: Diesel model structs (~User~, ~NewUser~)
  - ~lib.rs~ :: crate root, re-exports modules, defines shared types (~DbPool~)
  - ~error.rs~ :: unified ~AppError~ type and ~IntoResponse~ implementation
  - ~schema.rs~ :: Diesel ~table!~ macro (auto-generated by ~diesel print-schema~)
- ~tests/~
  - ~common/~ :: Test utilities
  - ~api_health.rs~ :: Test for ~/health~ API
  - ~api_users.rs~ :: Test for ~/users~ API
- ~devenv.nix~ / ~devenv.yaml~ :: [[https://devenv.sh][devenv]] configuration (Rust, PostgreSQL, packages)
- ~flake.nix~ :: Nix flake entry point, delegates to ~devenv~
- ~Justfile~ :: common task runner commands

** Common commands

| Command                      | Description                                      |
|------------------------------+--------------------------------------------------|
| ~devenv processes up~        | Start background services (DB)                   |
|------------------------------+--------------------------------------------------|
| ~just run~                   | Start the development server                     |
| ~just check~                 | Auto-format then run ~cargo check~               |
| ~just test~                  | Run all tests (requires background services)     |
| ~just test-unit~             | Run unit tests (standalone)                      |
| ~just build~                 | Build the server                                 |
| ~just lint~                  | Run ~cargo clippy~                               |
| ~just fmt~                   | Format code with ~treefmt~                       |
| ~just doc~                   | Generate documentation                           |
| ~just clean~                 | Cleanup artifacts                                |
|------------------------------+--------------------------------------------------|
| ~just db-setup~              | Initialise diesel                                |
| ~just db-migration-new NAME~ | Create a new migration scaffold                  |
| ~just db-migration-run~      | Run pending Diesel migrations                    |
| ~just db-migration-redo~     | Re-do last migration                             |
| ~just db-reset~              | Drop and recreate the database                   |
| ~just db-clean-state~        | Nuke devenv's pg state (after version switch)    |
|------------------------------+--------------------------------------------------|
| ~just ci~                    | Full CI pipeline: check + test + lint            |
| ~just ci-quick~              | Smoke test CI pipeline: check + lint + unit-test |
|------------------------------+--------------------------------------------------|
| ~just update~                | Update Nix flakes and Rust crates                |

Run ~just --list~ to see the full list.
