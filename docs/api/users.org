* /users                                                               :verb:
template http://localhost:3001

** List users                                                      :success:
get /users

Returns user objects.  The primary key ~id~ is always included; use
~?fields~ to request additional columns:

#+begin_src text
  GET /users
  # → [{"id": "…"}, …]

  GET /users?fields=name
  # → [{"id": "…", "name": "…"}, …]

  GET /users?fields=name,email
  # → [{"id": "…", "name": "…", "email": "…"}, …]
#+end_src

** Get existing user                                               :success:
get /users/<uuid>

** Get missing user                                                  :error:
# * Returns an HTTP 404 when the user doesn't match
#
#   Example,
#   {
#     "error": "User c84adc3d-9f09-44f8-b378-d770546d4719 not found"
#   }

get /users/c84adc3d-9f09-44f8-b378-d770546d4719

** Create user                                               :success:error:
# * Returns an HTTP 201 when a new valid user is created
#
# * Returns an HTTP 409 when the user's email is already registered
#
#   Example,
#   {
#     "error": "A user with this email already exists"
#   }
post /users
Content-Type: application/json
